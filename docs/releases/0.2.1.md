# LuxLedger 0.2.1

LuxLedger `0.2.1` is the coordinated OSS release-readiness set. Upgrade all public packages together:

| Package | Version |
| --- | --- |
| `@luxledger/core` | `0.2.1` |
| `@luxledger/http` | `0.2.1` |
| `@luxledger/postgres-adapter` | `0.2.1` |
| `@luxledger/fastify-routes` | `0.2.1` |
| `@luxledger/express-routes` | `0.2.1` |

This release coordinates the package and OpenAPI versions and adds deterministic release gates. It does not add hosted, paid, or Enterprise behavior and does not change ledger semantics.

## Database compatibility

The supported database contract remains the pre-production clean-install baseline. Reset databases created from the retired incremental history, apply `0000_initial-schema.sql`, and follow the backup/restore runbook. No in-place upgrade from the retired history is claimed.

## Verification

Run unit and PostgreSQL integration tests, typecheck, lint, build, contract verification, release-readiness checks, packed-package clean installation, and the PostgreSQL migration/restore drill before publication.
